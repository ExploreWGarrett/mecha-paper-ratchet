# Prototype Roadmap

## Phase 0 — Combat Toybox
Goal: prove the core feel.

### 0.1 Combat Toybox
- basic arena
- paper player presentation
- movement
- lock-on
- strafing
- shooting
- one enemy
- one projectile attack

### 0.2 Movement Kit
- double jump
- hover fall
- melee
- ground pound
- spin dodge

### 0.3 Basic Run Loop
- waves
- currency drops
- destroyables
- upgrade choices
- difficulty scaling

## Phase 1 — Combat Variety
### 1.1 Enemy Variety
- chaser
- shooter
- lobber
- exploder
- elite variant

### 1.2 Weapon Variety
- 3 to 5 weapons
- early upgrade interactions
- readable weapon identities

## Phase 2 — Run Structure
### 2.1 Room Progression
- room transitions
- reward room
- shop room
- challenge room
- elite or boss room

### 2.2 Modular Room Assembly
- handcrafted modules
- random room order
- entrance / exit compatibility
- spawn rules

## Phase 3 — Meta Layer
- unlockable characters
- unlockable weapons
- unlockable upgrades
- content-first progression

## Guardrail
If Phase 0 is not fun, do not proceed by adding more systems.
