# Inspiration Upgrade Reference Index

This folder is a research/reference drop for upgrade, mutation, powerup, and build-system inspiration.

## Why it exists
You wanted a few markdowns that keep the inspiration pool visible while we figure out which parts of the current upgrade vision actually feel right.

The goal of these notes is to:
- log the upgrade/powerup structure of the games you keep leaning on
- separate pure number-up ideas from synergy / build-shaping ideas
- keep track of character, weapon, ability, item, and mechanic reference lists we may want later
- compare 3D-valuable titles against strong 2D/system-dense titles
- add 1–2 extra titles that fit the same general lane

## Source coverage note
These docs are best-effort source-backed references, not perfect preservation copies of every external wiki.

- Some games had strong accessible wiki/API coverage.
- Some had sparse or partial public source coverage.
- `Stack Gun Heroes` and `Mega Bonk` in particular were much lighter on accessible public detail than the bigger roguelite references.
- `Above Land: Rhapsody` now sits in the same bucket as an exciting but still light-coverage early reference.
- Where a full machine-readable list was not accessible, the docs say so instead of pretending otherwise.
